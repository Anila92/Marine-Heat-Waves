# Marine-Heat-Waves
# Marine Heatwave Detection, Characterization & Bias Correction

Python workflows for **detecting and characterizing Marine Heatwaves (MHWs)** and evaluating climate-model SST simulations before and after bias correction.

## 🌊 What this repository contains

* MHW detection using the [`marineHeatWaves`](https://github.com/ecjoliver/marineHeatWaves) Python module.
* Generation and analysis of the **MHW event dictionary**.
* **Quantile-mapping bias correction** of climate-model SST (example using CanESM5 model).

## 🔬 Research Applications

The workflows are designed for studying:

* Marine heatwave frequency and duration
* Climate-model evaluation
* SST bias and its influence on MHW characteristics

## 💻 Tools

Python · NumPy · xarray · SciPy · Pandas · Matplotlib · Dask · `marineHeatWaves`
